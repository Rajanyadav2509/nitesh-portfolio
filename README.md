# Nitesh Kumar — Video Editor Portfolio

Static website. No build step, no server code.

## Files
- index.html  — the whole site (HTML, CSS, JavaScript)
- Nitesh_Kumar_CV.pdf — CV linked from the site
- covers/ — 29 video cover images
- media/ — 6 EduSure reels (compressed, hover-to-play)

## Deploy (free)
Netlify: unzip, then drag the folder onto https://app.netlify.com/drop
The contact form works automatically on Netlify (Netlify Forms).
Also works on Vercel, GitHub Pages, Cloudflare Pages or any static host:
upload these files with index.html at the root.

## Edit
- Videos in the work grid: search `const WORK = [` in index.html
- Featured videos: search `const FEAT = [`
- Profile photo: add `profile.jpg` next to index.html
